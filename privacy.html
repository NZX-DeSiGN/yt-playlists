yt-playlists : privacy policy

Last updated: [date of publication]

1. Who uses it

yt-playlists is a personal tool used by a single person, its author, on his or her own Google/YouTube account. There are no other users.

2. Data accessed

Through the YouTube Data API v3 (scope https://www.googleapis.com/auth/youtube), the tool reads the list of playlists of the account, and the identifiers, titles and channel names of the videos in them. It reads public metadata of videos (titles, channels, descriptions).

3. Data written

The tool creates, renames, fills and deletes playlists of the account owner. It writes nothing else.

4. Storage

Data is stored only on the author's own computer, in files readable by the author only. OAuth tokens are kept there with restricted permissions.

5. Sharing

No data is sold, published or sent to third parties. No advertising. Data obtained through the YouTube API is not used to train machine-learning models.

6. Google and YouTube

This application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

7. Revoking access and deleting data

Access can be revoked at any time at https://myaccount.google.com/permissions. Local files are deleted on simple request through an issue on this repository.

8. Contact

Open an issue on this repository (the "Issues" tab).
