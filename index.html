yt-playlists

A personal, single-user command-line tool that organises the developer's own YouTube playlists. It is not offered to the public and has no sign-up.

  • What it does: creates, renames and fills private playlists on the developer's own YouTube account through the YouTube Data API v3 (for example, a playlist of not-yet-watched videos of a channel, and playlists sorted by topic).
  • What it does not do: no access to other people's accounts, no advertising, no resale, no sharing of data, no data used to train models.
  • YouTube API Services: this application uses YouTube API Services. By using it, the developer agrees to be bound by the YouTube Terms of Service and the Google Privacy Policy.
  • Privacy policy: privacy.html
  • Contact: open an issue on this repository (the "Issues" tab).
